## 파일을 복사할 위치

GitHub Desktop에서 Repository → Show in Explorer로 연 CFO 저장소의 최상위 폴더에 복사하세요. public 폴더 안에 전체 파일을 붙여넣지 마세요. 정상 경로는 CFO/public/assets/js/version.js이며 CFO/public/public/assets/js/version.js는 잘못된 위치입니다. 기존 public/config.js를 보존하세요.

1. 먼저 Supabase에서 supabase/UPDATE_2_5.sql 전체를 실행하세요. 2.5.0에서 이미 실행했다면 생략할 수 있습니다. 재실행도 가능합니다.
2. changjin-finance-app 폴더 안의 내용물을 CFO 최상위 폴더에 병합·덮어씁니다.
3. GitHub Desktop에서 Commit 및 Push하고 Netlify 배포 완료를 기다립니다.
4. 웹사이트에서 Ctrl+F5 후 v2.5.1을 확인합니다.
5. 계좌 현황에서 법인을 선택하고 각 계좌의 잔액 반영을 누릅니다. 과거 자료만 있는 경우 실제 거래일을 확인합니다.

은행별 잔액은 선택한 계좌에 반영합니다. 예금·대출 상품은 은행 거래만으로 원금·이자·환매를 구분할 수 없으므로 기존 내부이체 연결과 상품 기준잔액 방식으로 관리합니다. 중복 정리는 관리창의 기존 중복 거래 정리에서 실행하세요. 실제 은행 거래가 없는 계좌는 원본 자료 업로드가 필요합니다.
