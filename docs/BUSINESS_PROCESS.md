# 업무 프로세스와 업무분장

## 1. 역할 정의

| 역할 | 주요 책임 | 등록·수정 | 승인·조회 |
|---|---|---|---|
| 현업 담당자 | 담당 입금·지급 예정, 거래 설명, 증빙·메모 | 본인 담당 자료 | 본인 처리현황 |
| 재무 담당자 | 은행자료 업로드, 거래분류, 예정·실적 연결 | 배정 법인의 재무자료 | 오류·누락 검토 |
| 자금·재무 관리자 | 법인별 수합, 자금전망, 보고서 작성 | 전체 재무자료 | 결재 요청·보관 |
| 결재자 | 보고서의 순차 검토 | 결재 의견 | 승인·반려 |
| 대표·임원 | 경영판단 | 원칙적으로 조회 | 대시보드·승인 보고서 |
| 관리자 | 계정·역할·법인·분류·백업 | 전 시스템 | 감사 이력 포함 |
| 감사·조회 | 변경내역·승인기록 확인 | 없음 | 조회 전용 |

## 2. 일상 업무 프로세스

1. 현업 담당자가 입금·지급 예정과 관련 설명을 입력합니다.
2. 재무 담당자가 은행 거래내역을 업로드합니다.
3. 시스템이 키워드 규칙으로 거래 분류를 추천합니다.
4. 재무 담당자가 분류와 예정 연결을 최종 확인합니다.
5. 자금담당자가 법인별 잔고·30일 최저잔고·추가 확보금액을 검토합니다.
6. 보고서를 스냅샷으로 저장하고 결재자를 순서대로 선택합니다.
7. 결재자는 승인 또는 반려하며 의견을 남깁니다.
8. 최종 승인 보고서는 보관되고 대표 대시보드와 과거 보고서에서 조회됩니다.
9. 모든 주요 수정과 결재행위는 감사로그로 남습니다.
