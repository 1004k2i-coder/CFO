# 첨부자료 분석 결과

## 1. 기존 HTML 프로그램

기존 `재무현황표_보고 최종_260626최종.html`은 다음 기능을 이미 보유하고 있습니다.

- 법인 3개(삼코, 삼천산업, 창진에스씨) 탭과 전체 합산
- 현재 통장잔고·필수보유현금·예정입금·예정지급·투자가능금액 계산
- 30일 자금과부족, 일자별 자금스케줄, 3개월 전망
- 단기투자·외화예금·자산배분·월별 수입지출
- Excel/CSV 업로드, JSON 백업, CSV 보고서
- 차트와 대표용 핵심 보고서

그러나 데이터가 브라우저 `localStorage`에만 저장되므로 다음 운영 위험이 있습니다.

- PC·브라우저별로 데이터가 분리됨
- 다중 사용자 동시 사용이 불가함
- 사용자별 입력권한·결재권한이 없음
- 수정자·수정일·변경 전후 값을 중앙에서 추적하기 어려움
- 승인된 보고서의 버전·보관체계가 없음

신규 시스템은 기존 계산·시각화 개념을 유지하면서 저장소를 Supabase PostgreSQL로 전환하고, 인증·역할·결재·감사기록을 추가합니다.

## 5. 첨부 화면 설계안

첨부 이미지는 역할별 정보량을 분리하는 방향을 제시합니다.

- 담당자 화면: 오늘 처리할 거래·연결·기한경과 중심
- 재무 관리자: 계좌·상품·자금계획·검토 요청 중심
- 대표·임원 화면: 현재 가용자금, 최저잔고, 부족액, 결정대기 중심
- 공통: 왼쪽 메뉴, 짙은 남색·청록색, 경고는 노란색·빨간색, 모바일 반응형

신규 UI는 이 원칙을 그대로 반영했습니다.
