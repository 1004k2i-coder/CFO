# 구현 현황 및 운영 전 확인사항

## 구현 완료

- Supabase 이메일 로그인과 세션 유지
- 역할 7종 및 법인별 접근권한
- 은행 거래내역·기존 34열 양식·과거 자금계획서·기존 HTML JSON 자동 판별
- 중복 거래 방지, 추천 분류, 예정/실적 연결
- 계좌·예금·대출·외화예금·실시간/수동환율·월별 계획 관리
- 보고서 스냅샷, 버전, 순차 승인·반려·보관
- 변경 전후 감사로그
- 대표·임원 경영 대시보드와 반응형 PWA
- Excel 다운로드, 구조화 데이터 전체 백업·복원
- GitHub Actions 정적 검사

## 운영 전 필수 확인

1. Supabase SQL 마이그레이션 실행
2. 최초 관리자 계정 부트스트랩
3. Netlify 환경변수 등록
4. 법인·계좌·사용자·분류 키워드 검수
5. 첨부 Excel 3종으로 이관 검수
6. 두 명 이상 결재선으로 승인·반려 시험
7. 모바일·태블릿·PC 확인
8. 백업 후 테스트 프로젝트 복원 시험
