# 기존 자료 이관 가이드

## 1. 권장 이관 순서

1. 법인과 사용자 등록
2. 계좌 등록
3. 기존 재무 입력양식 업로드
4. 과거 자금계획서 업로드
5. 은행 거래내역 업로드
6. 거래 분류·예정 연결 확인
7. 최초 기준 보고서 작성·승인

## 2. 기존 HTML JSON 백업

기존 HTML의 `데이터 백업 저장`으로 생성한 JSON을 신규 시스템의 `은행자료·기존자료 업로드`에 올리면 법인별 현금·월별 계획·입금지급 일정·자산·단기투자·외화예금을 자동 변환합니다. 이관 전후 법인명이 동일한지 확인하십시오.

## 3. 검증 항목

- 법인별 현재 잔고
- 필수보유현금
- 월별 수입·지출 합계
- 예정 입금·지급 건수와 합계
- 단기투자·외화예금 합계
- 최근 은행 거래의 마지막 잔액
- 동일 거래 중복 여부

## 4. 운영 전환

- 이관 검증 완료일까지 기존 HTML을 조회전용으로 유지합니다.
- 신규 시스템의 최초 승인 보고서가 완료되면 신규 시스템을 기준자료로 전환합니다.
- 기존 파일은 접근권한이 제한된 폴더에 보관하고 폐기일을 정합니다.
