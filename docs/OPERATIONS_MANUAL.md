# 비전문가용 운영 매뉴얼

## 1. 매일 하는 일

### 현업 담당자
1. `입금·지급 예정`에서 본인 담당 예정일·거래처·금액을 등록합니다.
2. 변경이 생기면 기존 건을 수정하고 메모에 사유를 적습니다.
3. 완료된 건은 상태를 `완료`로 바꿉니다.

### 재무 담당자
1. `은행자료 올리기`에서 법인과 계좌를 선택합니다.
2. 은행 Excel/CSV를 올리고 미리보기의 일시·입출금·잔액을 확인합니다.
3. `확인할 거래`에서 추천 분류를 검토하고 예정 항목과 연결합니다.
4. 중복·누락·기한경과 알림을 확인합니다.

### 자금·재무 관리자
1. `오늘 할 일`에서 미확인 거래·기한경과·결재 대기를 확인합니다.
2. `계좌·대출·예금`에서 기준일과 잔고를 갱신합니다.
3. `검토·보고`에서 보고서 스냅샷을 만들고 결재자를 순서대로 지정합니다.
4. 최종 승인된 보고서는 `보관` 처리합니다.

### 결재자·대표·임원
1. `결재함`에서 보고 요약과 주요 지표를 확인합니다.
2. 승인 또는 반려를 선택하고 의견을 기록합니다.
3. `경영 대시보드`에서 30일 최저잔고·추가 확보액·법인별 부족액을 확인합니다.

## 2. 월말 업무

1. 모든 법인의 은행자료 업로드 완료 여부 확인
2. 예정과 실제 거래 연결 완료 여부 확인
3. 계좌잔고 기준일 확인
4. 단기예금·대출·외화예금 만기 및 사용제한 여부 확인
5. 월간 보고서 작성 → 결재 → 보관
6. `전체 백업` JSON 다운로드
7. Excel 다운로드 파일과 백업 파일을 회사 지정 보안폴더에 보관

## 3. 사용자 관리

- 신규 입사자: 관리자 설정에서 사용자·역할·법인권한 등록
- 부서 이동자: 역할과 법인권한 수정
- 퇴사자: **삭제하지 않고 비활성화**하여 작성·결재·수정 이력을 보존
- 대표·임원: 조회 및 결재 중심 권한 권장
- 현업 담당자: `현업 입력` 권한 권장
- 재무 담당자: `재무 관리` 권한 권장

## 4. 오류가 발생했을 때

### Excel이 읽히지 않을 때
- 확장자가 `.xlsx`, `.xls`, `.csv`인지 확인
- 제목·열 이름이 변경되지 않았는지 확인
- 날짜 셀에 오류값이 없는지 확인
- 파일을 Excel에서 다시 저장한 후 재시도

### 같은 거래가 다시 올라오지 않을 때
정상 동작입니다. 거래일시·적요·금액·내용·잔액 조합의 해시로 중복을 제외합니다.

### 대시보드 숫자가 다를 때
1. 법인 선택 확인
2. 계좌잔고 기준일 확인
3. 예정 입금확률 확인
4. 계좌이체가 비용에서 제외되었는지 확인
5. 기한이 지난 일정 상태 확인

### 사용자가 로그인하지 못할 때
관리자가 사용자 상태가 `사용`인지 확인하고, 필요하면 비밀번호를 재설정합니다.

## 5. 백업·복원 원칙

- 월 1회 이상 JSON 전체 데이터 백업
- 분기 1회 테스트 프로젝트에서 복원 시험
- 원본 은행파일은 Supabase Storage에 별도 보관
- 복원은 관리자만 수행
- 감사로그는 기존 이력을 훼손하지 않기 위해 자동 복원하지 않음
