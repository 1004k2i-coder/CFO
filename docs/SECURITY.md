# 보안 운영 지침

1. Supabase `service_role` 키는 Netlify 환경변수에만 저장합니다.
2. 실제 계좌번호 전체는 저장하지 않고 마스킹 번호만 사용합니다.
3. 원본 은행파일 버킷은 비공개로 유지합니다.
4. 사용자는 필요한 법인과 역할만 부여합니다.
5. 퇴사자는 즉시 비활성 처리하고 작성·결재·감사 이력은 보존합니다.
6. 대표·임원은 원칙적으로 조회권한을 부여합니다.
7. 반려·승인 의견에는 주민번호·전체 계좌번호 등 민감정보를 기록하지 않습니다.
8. Excel 다운로드 파일은 회사 보안정책에 따라 암호화·폐기합니다.
9. 월 1회 사용자·권한을 점검합니다.
10. 월 1회 전체 백업을 내려받고 분기 1회 복원시험을 실시합니다.
11. 운영 전 MFA, 비밀번호 정책, 로그인 감사로그를 검토합니다.
12. 데이터 정합성 검증 없이 자동 분류를 확정하지 않습니다.
