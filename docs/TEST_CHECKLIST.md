# 사용자 검수 체크리스트

## 로그인·권한
- [ ] 현업 담당자는 관리자 메뉴를 볼 수 없음
- [ ] 대표·임원은 재무 원본을 수정할 수 없음
- [ ] 결재자는 본인에게 배정된 결재만 처리 가능
- [ ] 법인 미배정 사용자는 해당 법인 데이터를 볼 수 없음

## 업로드
- [ ] 은행 Excel 287행이 정상 미리보기 됨
- [ ] 동일 파일 재업로드 시 중복이 제외됨
- [ ] 기존 34열 재무양식이 현금·월별·일정·자산·상품으로 분리됨
- [ ] 과거 자금계획서의 공란 일자가 직전 일자로 연결됨
- [ ] 원본파일이 Storage에 저장됨
- [ ] 기존 HTML JSON 백업이 현금·월별·일정·상품으로 변환됨
- [ ] 외화예금의 수동환율과 원화환산액이 일치함

## 거래·일정
- [ ] 추천 분류가 표시됨
- [ ] 분류 확정 후 상태가 확인완료로 변경됨
- [ ] 예정과 실적 연결 시 일정 상태가 변경됨
- [ ] 기한경과 일정이 오늘 할 일에 표시됨

## 결재
- [ ] 결재자를 두 명 이상 순서대로 선택 가능
- [ ] 1차 승인 전 2차 결재가 불가함
- [ ] 반려 사유가 기록됨
- [ ] 전원 승인 후 보관 가능
- [ ] 수정 전후와 보고서 버전이 조회됨

## 대시보드
- [ ] 현재 가용자금이 계좌합계와 일치
- [ ] 30일 입금은 확률을 반영
- [ ] 계좌이체는 비용에서 제외
- [ ] 법인별 부족액과 전체합계가 일치
- [ ] 모바일·태블릿·PC에서 화면이 정상 표시됨

## 백업
- [ ] 전체 JSON 백업 다운로드 가능
- [ ] 테스트 프로젝트에서 복원 성공
- [ ] 원본 파일 Storage 경로가 유지됨
