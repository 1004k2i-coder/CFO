# v2.7.2 업데이트 안내

경영대시보드에 총 보유자금(MMT·예금 포함)을 별도로 표시합니다. 통장 잔액 + 활성 금융상품 현재 잔액(대출상품 제외)입니다. 외화는 저장 환율로 원화 환산합니다. 삭제 상품은 제외하며 선택 법인에 따라 집계됩니다. 기존 현재 가용자금 및 30일 전망은 유지합니다.

담보·만기 제한 상품도 포함하는 보유금액이며 즉시 사용 가능 금액은 아닙니다. 동일 MMT를 계좌와 상품에 모두 등록하면 중복 합산되므로 한 곳에서만 잔액을 관리하세요. 대출상품 잔액은 더하거나 빼지 않습니다. 통장에 이미 입금된 대출금은 통장 잔액의 일부로 포함됩니다.

압축 내부 changjin-finance-app 폴더의 내용을 기존 CFO 저장소 최상위(package.json 위치)에 덮어쓰세요. public 안에 전체 파일을 넣지 마세요. 기존 public/config.js는 보존하며 압축파일에 포함하지 않았습니다. GitHub Desktop에서 커밋 후 Push origin을 진행하고 Netlify 배포 완료 후 Ctrl+Shift+R로 새로고침하세요.

v2.7.1에서 추가 SQL은 필요하지 않습니다. 이전 DB 설치 오류는 별도로 해결해야 합니다. 운영 사이트 배포는 수행하지 않았습니다.
