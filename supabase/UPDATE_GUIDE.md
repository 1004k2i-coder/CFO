# 2.6.0 간편 자금이동 업데이트

## 적용 순서

1. Supabase SQL Editor에서 supabase/APPLY_UPDATE.sql 전체를 실행합니다. 기존 2.4 이후 버전에 필요한 2.5와 2.6 변경을 포함하며 재실행 가능합니다.
2. 압축 안 changjin-finance-app의 내용물을 CFO 저장소 최상위 폴더에 병합·덮어씁니다. public 폴더 안에 전체 파일을 넣지 마세요. 기존 public/config.js는 보존합니다.
3. Commit·Push 후 Netlify 배포 완료를 기다립니다. Ctrl+F5 후 v2.6.0을 확인하세요.

## 가장 간단한 사용법

확인할 거래에서 MMT 예치·회수 또는 회사 계좌 사이 이동을 선택하고, 확정 분류를 자금이동 (수입·지출 제외)으로 지정한 뒤 확인완료를 누릅니다. 상대 계좌 선택창이 자동으로 열리지 않으며 연결 없이 저장됩니다. 여러 건은 체크 후 선택 분류 적용, 다시 체크 후 선택 거래 확인완료로 처리합니다.

자금이동 입금과 출금 모두 수입·지출 분석에서 제외됩니다. 수수료는 지급수수료, 이자는 이자수익 등 실제 성격에 맞게 따로 분류하세요.

잔액은 각 계좌의 은행자료에 기록된 최신 거래후 잔액으로 관리합니다. 자금이동 분류만으로 상대 MMT 잔액을 임의로 더하거나 빼지 않습니다. 양쪽 자료의 기준시점을 맞추고, 같은 MMT를 은행계좌와 금융상품 양쪽에 중복 등록하지 마세요. 자료가 없는 상품은 실제 잔액을 입력해야 합니다.

이미 연결한 거래와 상품 증감은 보존됩니다. 기존 연결 관리를 펼쳐 확인할 수 있습니다. 예전 연결 상품을 은행계좌 방식으로 전환할 때에는 실제 잔액과 중복 등록을 먼저 확인하세요. 기존 연결 거래를 일반 비용으로 바꾸려면 연결 해제 후 분류합니다.

은행 업로드 중복 제외·계좌별 잔액 반영·삭제·CFO 13주 보고·작업 백업 기능을 포함합니다. 실제 운영 사이트 배포는 사용자가 적용해야 합니다.
