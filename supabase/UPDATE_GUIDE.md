# v2.7.1 업데이트 안내

## 변경 내용

은행자료 파일명 끝에 복사 번호가 붙어도 업로드할 수 있습니다.
- 202601_03sb.xlsx
- 202601_03sb(2).xlsx
- 202601_03sb.xlsx(2)

확장자 앞에 번호가 붙은 파일은 기존에도 지원했습니다. 이번 보완은 확장자 뒤 번호까지 처리하고 파일 선택창에서 선택할 수 있도록 한 것입니다. 파일 선택창에는 모든 파일이 표시되지만 실제 지원 형식은 xlsx, xls, csv, json입니다. 암호가 걸린 파일이나 지원하지 않는 은행 양식은 별도 확인이 필요합니다.

원래 파일명은 업로드 이력에 보관하고 서버 저장 경로는 기존처럼 영문·숫자로 생성합니다. 같은 계좌의 기존 거래 중복 제외 방식은 유지합니다. 다른 계좌로 선택하면 별도 거래로 처리되므로 대상 계좌를 정확히 선택하세요.

## 설치 방법

1. 기존 저장소를 별도 폴더에 복사하여 보관하세요.
2. 압축을 풀고 changjin-finance-app 폴더 안의 내용을 기존 CFO 저장소 최상위에 덮어쓰세요. package.json과 netlify.toml이 있는 위치입니다. public 폴더 안에 전체 파일을 넣지 마세요.
3. 기존 public/config.js는 그대로 유지하세요. 업데이트 압축파일에는 config.js가 없습니다.
4. GitHub Desktop에서 변경 내용을 커밋하고 Push origin을 누르세요.
5. Netlify 배포 완료 후 Ctrl+Shift+R로 새로고침하고 v2.7.1 표시를 확인하세요.

## SQL 및 검증 범위

v2.7.0에서 이번 변경을 적용할 때 추가 SQL은 필요하지 않습니다. 이전의 financial_products 테이블 없음 오류를 해결하는 업데이트는 아닙니다. 데이터베이스 설치가 미완료된 경우에는 기존 오류를 먼저 해결해야 저장할 수 있습니다. INSTALL_ALL.sql을 임의로 재실행하지 마세요.

첨부 은행자료의 원래 이름과 복사 번호를 붙인 이름으로 파싱 결과·파일 해시·거래 해시가 동일한지 검증했습니다. 실제 운영 사이트 업로드와 배포는 수행하지 않았습니다. 은행 원본과 개인 자료는 압축파일에 포함하지 않았습니다.
