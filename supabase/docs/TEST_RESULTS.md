# 검증 결과와 인수시험 범위

## 완료된 검증

- 자바스크립트 문법 검사
- 기능 단위시험 10개: 기존 변환·현금흐름·법인 합산·보고 스냅샷·외화·공개 키 검증·관리 RPC 전달·파일 구조
- 통합 SQL 최초 실행과 동일 버전 재실행
- 미승인 관리자와 일반 사용자의 전체 백업 차단
- 자기 프로필 권한 상승 및 일반 사용자 관리자 RPC 차단
- 다른 계정의 기기 토큰 재사용 차단
- 다른 법인의 자료 조회·쓰기 차단
- 결재 상태 직접 변경 차단
- 제출·반려·재제출·승인·보관
- 업무 백업·복원과 오류 발생 시 전체 롤백
- 철회 기기의 조회·결재 차단 및 재등록으로 철회 우회 방지
- 기기 헤더 없는 Storage 테이블 쓰기 차단
- 익명 업무 RPC 실행 차단
- DOM 기반 로그인·기기 신청·승인 대기·관리자 화면 기능 시험
- PDF 두 문서 각 10쪽의 한글·표·쪽번호·잘림 육안 검수

## 검증 환경의 한계

SQL 검증은 PGlite 임시 PostgreSQL 환경에서 Supabase의 auth·storage 스키마를 모사해 수행했습니다. 실제 Supabase Gateway, Auth 메일, Storage 업로드 HTTP, Netlify 배포를 대신하는 시험은 아닙니다. 브라우저 실행 제한으로 실제 Chromium 화면 렌더링 시험은 수행하지 못했으며 DOM 기반 화면 기능 시험으로 보완했습니다. 실제 서비스 연결, 모바일 화면, 실제 은행 파일, 환율 조회 및 대량 자료는 설치 설명서의 인수시험표에 따라 확인해야 합니다.
